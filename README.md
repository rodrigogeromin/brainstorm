# Brainstorm

Repositório para armazenar e desenvolver brainstorms de ideias, preservando contexto, alternativas, hipóteses, decisões e próximos passos.

## Organização

- [brainstorms/](brainstorms/README.md): ideias e índice dos registros.
- [templates/brainstorm.md](templates/brainstorm.md): modelo para iniciar uma discussão.

## Como registrar uma ideia

1. Copie o modelo para `brainstorms/AAAA-MM-DD-tema-da-ideia.md`.
2. Preencha as seções úteis para a discussão; o registro pode começar incompleto.
3. Adicione o link ao índice de brainstorms.
4. Atualize o mesmo arquivo conforme a ideia evoluir, mantendo o histórico no Git.

## Status sugeridos

- **Em exploração**: levantamento de possibilidades e perguntas.
- **Em validação**: experimentos para testar hipóteses.
- **Decidido**: direção escolhida e justificativa registrada.
- **Arquivado**: discussão encerrada ou pausada.

Ideias são propostas em evolução. Registre explicitamente quando uma hipótese se tornar uma decisão.
