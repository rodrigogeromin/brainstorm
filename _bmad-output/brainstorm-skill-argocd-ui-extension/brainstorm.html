Construir projetos de Argo CD UI Extension com velocidade e assertividade, tomando práticas codificadas como base e escolhendo a referência conforme a versão e o caso real.

Evidência

Contrato do host

A base comum observada está na integração com Argo CD. Os projetos têm estruturas e ferramentas diferentes.

Recomendação

Adaptar uma referência

Selecionar uma implementação compatível e adaptar domínio, registro e integração necessários.

Pendência

Validar na versão alvo

Versão, primeiro caso real, backend e instalação ainda precisam ser definidos. Não houve compilação nem instalação nesta pesquisa.

Contratos recorrentes

Evidência

Runtime compartilhado

React compartilhado com o host. O guia oficial para Argo CD 3.5 exige runtime JSX externo; bibliotecas podem continuar incompatíveis.

Evidência

Registro e bundle

extensionsAPI e JavaScript extension*.js compõem a base comum observada.

Evidência

Entrega ao servidor

Instalação no argocd-server. O Installer documenta uma forma concreta de entregar recursos.

Limites e decisão de escopo

A amostra foi dirigida a projetos ArgoProj Labs. Ela não representa todos os desenvolvedores nem demonstra consenso universal. A inspeção do Example Extension e de Ephemeral Access foi limitada.

Não foi identificada uma skill pronta de Codex nesta amostra; isso não prova sua inexistência. A recomendação é derivada dos projetos observados, sem estabelecer uma árvore universal, um gestor de pacotes obrigatório ou um bundler universal.

O resultado é pesquisa e brainstorm com fontes. A implementação da skill e de um scaffold fica para uma etapa posterior, após definir o caso e validar a referência.
