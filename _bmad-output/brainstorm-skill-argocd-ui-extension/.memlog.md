- (insight by coach) argocd-example-extension é template público; árvore e build não ficaram disponíveis para inspeção suficiente. Fonte https://github.com/argoproj-labs/argocd-example-extension
- (insight by coach) Rollout Extension tem ui/src/index.tsx, webpack.config.js e manifests; código React/TypeScript com registro de recurso. Fontes https://github.com/argoproj-labs/rollout-extension/tree/master/ui e https://github.com/argoproj-labs/rollout-extension/blob/master/ui/src/index.tsx
- (insight by coach) Webpack do Rollout externaliza react, react-dom e react/jsx-runtime; usa ts-loader e evita estilos globais de argo-ui. Fonte https://raw.githubusercontent.com/argoproj-labs/rollout-extension/master/ui/webpack.config.js
- (insight by coach) Rollout PR 104 corrigiu conflito com React 19; compatibilidade documentada v0.4.0+ com Argo CD 3.5+. Fonte https://github.com/argoproj-labs/rollout-extension/pull/104
- (insight by coach) Guia oficial Argo CD 3.5 exige runtime JSX externo; versões das bibliotecas também podem continuar incompatíveis. Fonte https://argo-cd.readthedocs.io/en/stable/operator-manual/upgrading/ui-extensions-react-19-upgrading/
- (insight by coach) Metrics separa UI de servidor que consulta Prometheus; usa proxy extension, RBAC e extension.config. Fonte https://github.com/argoproj-labs/argocd-extension-metrics
- (insight by coach) Metrics usa pasta extensions/resource-metrics/resource-metrics-extention e yarn.lock; layout difere do Rollout. Fonte https://github.com/argoproj-labs/argocd-extension-metrics/tree/main/extensions/resource-metrics/resource-metrics-extention
- (insight by coach) Assistant package.json define build com webpack/ts-node e empacota dist/resources em tar; usa Yarn. Fonte https://github.com/argoproj-labs/assistant-for-argocd/blob/main/package.json
- (insight by coach) Assistant documenta integração via proxy, cópia local para desenvolvimento e dificuldades de dependências. Fonte https://github.com/argoproj-labs/assistant-for-argocd
- (insight by coach) Não foi possível inspecionar Ephemeral Access em profundidade; referência oficial à correção 141 é evidência limitada, não auditoria.
- (insight by coach) Installer documenta init container, diretório resources no tar, URL/version/name e checksum opcional. Fonte https://github.com/argoproj-labs/argocd-extension-installer
- (insight by coach) Antigo argocd-extensions está depreciado; não adotar o controlador antigo como base. Fonte https://github.com/argoproj-labs/argocd-extensions
- (technique by coach) started Solution Matrix: comparar tipo de UI, fonte de dados, build e distribuição observados.
- (insight by coach) Base comum observada é contrato do host, não árvore universal: React compartilhado, extensionsAPI, JS extension*.js e instalação no argocd-server.
- (idea by coach) Recomendação derivada: skill seleciona implementação de referência compatível com versão alvo e adapta apenas domínio, registro e integração necessários.
- (idea by coach) Recomendação derivada: para UI com backend, usar Metrics como referência de proxy e permissões; não gerar backend obrigatório para toda extensão.
- (idea by coach) Recomendação derivada: preservar gestor de pacotes e lockfile da base; não universalizar Yarn, pnpm ou um bundler sem evidência.
- (technique by coach) started Decision Tree Mapping: versão alvo, ponto de extensão, fonte de dados e método de instalação determinam a base.
